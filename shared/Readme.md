# Shared

Short description
- `shared` contains common models, services and logic used by other parts of the application (e.g., `Documents`, `Blocks`, `Projects`, `Serialization`, `Services`).

Main elements
- `Documents` — types and logic related to documents (e.g., `VibDocument.cs`).
- `Blocks` — basic building blocks of the application (e.g., `VibBlock.cs`).
- `Projects` — project representation and related logic (e.g., `VibProject.cs`).
- `Serialization` — serialization/deserialization of documents (e.g., `VibDocumentSerializer.cs`).
- `Services` — services operating on models (e.g., `VibProjectService.cs`).
