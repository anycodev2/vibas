# Shared

Krótki opis
- `shared` zawiera wspólne modele, serwisy i logikę używaną przez pozostałe części aplikacji (np. `Documents`, `Blocks`, `Projects`, `Serialization`, `Services`).


Główne elementy
- `Documents` — typy i logika dotycząca dokumentów (np. `VibDocument.cs`).
- `Blocks` — podstawowe bloki aplikacji (np. `VibBlock.cs`).
- `Projects` — reprezentacja projektów i powiązana logika (np. `VibProject.cs`).
- `Serialization` — serializacja/deserializacja dokumentów (np. `VibDocumentSerializer.cs`).
- `Services` — serwisy operujące na modelach (np. `VibProjectService.cs`).
